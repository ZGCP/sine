## 三、使用方法

### 快速开始

1. **安装APK**
   - 下载 `xian_v1.0.0.apk`
   - 卸载旧版本弦应用商店（如有）
   - 安装新APK

2. **登录**
   - 使用**灵应用商店**的账号密码登录
   - 没有账号建议到灵应用商店官网注册

3. **下载安装应用**
   - 浏览应用列表
   - 点击下载
   - 下载完成后点击安装
   - 首次安装会弹出"安装未知应用"权限页面，授权后返回重试

### 注意事项

- 注册功能时好时坏，不建议在本应用内注册
- 若账号仅注册但未验证邮箱，下载速度可能受到限制；已验证邮箱的用户可正常下载，但可能受到网络影响
- 首次打开可能加载较慢，请耐心等待
- 下载的APK保存在 `/sdcard/Download/SineMarket/` 目录
- 如APP内安装失败，可手动到下载目录点击APK安装
